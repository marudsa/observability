# Observability Lab

Hands-on observability exercise using Prometheus, Grafana and Alertmanager to monitor services and generate notifications through Microsoft Teams.

## Components

- **Prometheus** — Metrics collection and monitoring.
- **Grafana** — Metrics visualization and dashboards.
- **Alertmanager** — Alert management and routing.
- **Microsoft Teams** — Notification channel for alerts.
- **Docker Compose** — Local environment orchestration.

## Repository structure

- `prometheus.yml` — Prometheus configuration.
- `alertrules.yaml` — Alerting rules.
- `config.yml` — Alertmanager configuration.
- `docker-compose.yml` — Local observability stack.

## Purpose

This repository was created as a practical exercise to explore monitoring, alerting and observability concepts using open-source tools.
